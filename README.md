# HERITAGE — Maison Horlogère & E-Commerce Premium (Abidjan)

Plateforme e-commerce officielle de la Maison **HERITAGE**, dédiée à l'horlogerie d'exception et aux accessoires de prestige à Abidjan, Côte d'Ivoire.

> *« Portez aujourd'hui ce que vous transmettrez demain. »*

---

## 🏛️ Caractéristiques

- **Catalogue Horloger de Précision** : Modèles suisses certifiés (*Tissot Le Locle, Chemin des Tourelles, Seastar 1000, PR516, PR100*).
- **Fiches Produits Riches** : Galerie haute définition, mouvements automatiques Powermatic 80 / quartz suisse, fiches techniques et certificat de garantie 2 ans.
- **Paiements Locaux & Internationaux** : Intégration Wave Mobile Money, Orange Money CI, MTN MoMo, Moov Money et Cartes Bancaires (Visa / Mastercard).
- **Livraison Sécurisée & Retrait sur Mesure** : Acheminement sous pli scellé dans toutes les communes d'Abidjan ou remise en main propre à la Maison HERITAGE (Yopougon).
- **Conformité Réglementaire** : Respect de la loi ivoirienne N° 2013-450 sur la protection des données (ARTCI), mentions légales et CGV complètes.

## 🚀 Démarrage Rapide

### Prérequis
- Node.js (v18+)
- npm ou bun

### Installation
```bash
npm install
```

### Lancement en mode développement
```bash
npm run dev
```
L'application démarre sur `http://localhost:3000`.

### Compilation de production
```bash
npm run build
```

---

## 🛠️ Stack Technique

- **Frontend** : React 19, TypeScript, Vite
- **Styling** : Tailwind CSS v4, Lucide Icons, Motion
- **Architecture** : Context API avec persistance locale et typage rigoureux
- **Hébergement & Déploiement** : Google Cloud Run / Google AI Studio
